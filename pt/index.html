Sete sinais, e como cada um se lê

Cada expressão desta página vem com a leitura em voz alta logo abaixo. Esta folha diz o que cada tipo de sinal é.

Nenhum sinal aparece antes de estar nesta folha. Letra grega não é o assunto de nenhum degrau. Onde o símbolo é mais curto que a frase, a frase vence.

0 · antes de qualquer máquina

A frase já é um código

Dizer olá mundo em voz alta é um código. Escrever é outro. Piscar uma lanterna é um terceiro.

Código aqui não é segredo: é um combinado sobre o que cada sinal quer dizer. Muda o meio, fica a mensagem. A lanterna já obriga a escolher: dois tipos de piscada, e nada mais.

1 · letra → número

Cada letra recebe um número

O o vale 111. O l, 108. O espaço também é uma letra: 32. A frase vira uma fila de nove números.

Não há nada de o no 111. É uma posição numa tabela que o mundo inteiro combinou usar. Por isso o mesmo o é 111 em qualquer máquina.

a matemática daqui · correspondência um a um entre letras e números

número(o) = 111

lê-se: número de o é igual a cento e onze.

2 · número → bits

Cada número vira oito casas de sim ou não

111 vira 01101111. Oito casas, cada uma só 0 ou 1. Com oito casas cabem 256 coisas diferentes.

É a mesma ideia de 111 = 100 + 10 + 1, só que cada casa vale o dobro da vizinha, não dez vezes. 256 é o número de combinações, não um tamanho.

a matemática daqui · notação posicional na base dois

111 = 64 + 32 + 8 + 4 + 2 + 1

lê-se: cento e onze é igual a sessenta e quatro, mais trinta e dois, mais oito, mais quatro, mais dois, mais um.

28 = 256

lê-se: dois elevado a oito é igual a duzentos e cinquenta e seis: o tamanho do conjunto das listas de oito zeros ou uns.

2½ · o degrau que o personagem trouxe

O á não cabe em um byte

225 é maior que 127, e o combinado original só tinha 128 letras, sem acento. O á custa dois bytes.

Nove letras, dez bytes. Byte não é letra: uma letra pode custar um, dois, três ou quatro. Quem conta bytes para contar letras erra, e a web inteira já errou isso.

a matemática daqui · código de comprimento variável, sem palavra que seja começo de outra

bytes(o) = 1, bytes(á) = 2

lê-se: bytes de o é igual a um; bytes de á é igual a dois.

3 · bit → corrente

Cada casa vira corrente num relé

O 1 é corrente passando; o 0 é corrente parada. Oito relés enfileirados seguram o o; oitenta seguram a frase.

O número não está no relé. O relé só sabe passar ou não passar; somos nós que combinamos que passar vale 1. Daqui para cima, a escada que já existe sobe com citação e instrumento.

a matemática daqui · limiar: um intervalo inteiro de tensões vira um símbolo só

bit(v) = 1 se v ≥ 2 volts, e 0 se v ≤ 0,8 volt

lê-se: bit de vê é igual a um se vê é maior ou igual a dois volts, e igual a zero se vê é menor ou igual a zero vírgula oito volt.

4 · corrente → conta e lembrança

Os bits aprendem a somar e a ficar parados

Portas ligadas de um jeito somam dois bytes. Ligadas de outro, seguram um bit depois que a entrada some.

Somar 1 ao o dá p, a letra seguinte: a tabela foi feita para isso funcionar. Agora o número pode ser operado e pode esperar. Lembrar é o que permite o próximo degrau.

a matemática daqui · aritmética módulo 256, e estado que depende do anterior

(111 + 1) mod 256 = 112

lê-se: cento e onze mais um, módulo duzentos e cinquenta e seis, é igual a cento e doze.

st+1 = f(st, xt)

lê-se: o estado no instante tê mais um é f de: o estado no instante tê, e a entrada no instante tê.

5 · byte → endereço

Cada byte ganha um lugar com número

Memória é uma fileira de gavetas, cada uma com um número na porta. O o fica na gaveta 0109; o l, na 010A.

Agora há dois números por letra: o que ela vale e onde ela está. A ordem das letras virou ordem de endereços. Ler a frase é percorrer gavetas vizinhas.

a matemática daqui · a memória é uma regra que leva cada endereço num byte

mem(0109) = 6F

lê-se: mem de zero, um, zero, nove é igual a seis-efe, que vale cento e onze.

6 · número → ordem

Um número é lido como ordem, não como quantidade

Na mesma memória, ao lado das letras, moram outros bytes. CD não é letra: é a ordem “chame”. C9 é “volte”.

Nada no byte diz se ele é letra ou ordem. O que decide é para onde o contador de programa aponta, e esse contador também é um número guardado na máquina. A máquina se governa com a mesma matéria que governa.

a matemática daqui · a máquina é uma regra de passo: do estado de agora para o próximo

próximo = passo(PC, A, mem)

lê-se: o próximo estado é passo de: o contador de programa, o registrador A, e a memória.

7 · palavras → ordens

Alguém escreve as ordens com palavras

Ninguém decora que “chame” é CD. Escreve-se CALL 5 num texto, e o montador troca cada palavra pelo byte certo.

É aqui que a delegação começa: a pessoa escreve a intenção, a máquina executa. O sistema operacional já sabe fazer serviços, como mostrar texto, para que cada programa não precise saber.

a matemática daqui · tradução que preserva significado

roda(montar(texto)) = significado(texto)

lê-se: rodar o que foi montado do texto dá o mesmo que o significado do texto.

8 · execução → tela

A ordem vira pontos de luz

A tela também é memória: cada três bytes são um ponto colorido. Mostrar o o é escrever números nas gavetas certas desse bloco.

Sessenta vezes por segundo a tela lê o bloco e acende. olá mundo volta a ser coisa que a gente lê, feita de números. Como o 111 vira o desenho do o é o buraco declarado deste mapa.

a matemática daqui · regra que leva cada ponto da grade numa cor

cor(3, 4) = 16 23 3F

lê-se: cor de três e quatro é igual a um-seis, dois-três, três-efe: vermelho, verde e azul.

fecho

Em cada degrau, uma coisa se conserva e uma se esquece

A matemática se refere ao mundo por aquilo que se conserva. Cada camada é uma promessa: “pode esquecer o resto, isto eu garanto”.

A escada inteira é a cadeia dessas promessas, e a execução é o que sobra quando todas foram cumpridas.

buracos declarados
  • do 111 ao desenho do o (fonte tipográfica e rasterização): sem passagem no Petzold; outro livro, ou ofício do autor, datado
  • do teclado ao número (Petzold cap. 25 — Peripherals): deve cobrir; não copiado ainda
  • a tabela ASCII em si (Petzold cap. 13): está no capítulo e não foi copiada; os números do degrau 1 são derivados
  • o á em 1978 (Petzold cap. 27): o programa é de antes do Unicode; a versão com “olá mundo” é adaptação do autor
  • da tela à web (Petzold cap. 27): o capítulo termina com a mesma frase em JavaScript numa página; ainda não lido
