before everything · how to read the symbols on this page

Seven signals, and how each is read

Each expression on this page comes with the reading aloud right below. This sheet says what each type of signal is.

number(o)

name in straight letters, with parentheses: a rule with a name, applied to what is inside the parentheses. read as: number of o.

v, t

slanted lowercase letter: a quantity that varies. read as: see, have.

st

index below: at which instant, or at which position. read as: ess at instant tee.

28

small number on top: how many times to multiply the number by itself. read as: two to the eighth.

(79 + 1) mod 256

mod: the remainder of division by. read as: seventy-nine plus one, modulo two hundred and fifty-six.

signals → meanings

arrow between two sets: a rule that takes each thing from the left to a thing on the right. read as: takes signals into meanings.

4F

number in hexadecimal: a number written with the digits from 0 to 9 and the letters from A to F, which are worth 10 to 15. read as: four-ef, which is seventy-nine.

No sign appears before it is on this sheet. In every step, the new words come explained before they appear. Where the symbol is shorter than the sentence, the sentence wins.

0 · before any machine

The sentence is already a code.

Saying Olá, Mundo! out loud is a code. Writing it is another. Blinking a flashlight is a third.

before, the words of this step

signal

  • What it is: anything that can be perceived: a sound, a mark on paper, a light turned on.
  • Why it exists: it's what travels from the speaker to the listener; the message itself doesn't travel alone.

code

  • What it is: a combination about what each signal means.
  • Why it exists: for the message to cross a medium that is not the voice: paper, light, wire.

Code here is not a secret: it's an agreement about what each signal means. Changes the medium, stays the message. The lantern already forces a choice: two types of blinking, and nothing more.

read as: code assigns each signal a single meaning, and it's reversible.

½ · key → number

The key becomes a number

Pressing the key O closes a switch. The machine looks at a special drawer, number 8200, and finds 79. The key turned into a number.

before, the words of this step

switch

  • What it is: a part that opens or closes a path. The light switch is a switch; so is every key.
  • Why it exists: to turn something on or off with a touch.

drawer

  • What it is: a place inside the machine where a number fits, with a number at the door to be found again.
  • Why it exists: the machine cannot see the key; it only knows how to look at drawers. The keyboard leaves its number in one of them.

The machine looks at the drawer all the time and almost always finds zero: no one pressed it. The book calls this checking the keyboard. When it finds 79, it copies to the screen and zeros the drawer, ready for the next key.

see on the board → echo, cycle 22: the drawer 8200 delivers the 79 to the machine; ten steps later it is on the screen

key(t) = 79 while the O is pressed, and 0 afterwards

read as: key of tee equals seventy-nine while the O is pressed, and zero afterwards.

1 · letter → number

Each letter receives a number

The O is 79. The l is 108. The comma is 44 and the space, 32. The sentence becomes a line of eleven numbers.

before, the words of this step

table

  • O que é: a list in which each letter has its number next to it, like a roll call.
  • Why it exists: the machine only stores numbers; the table is the combination that says which number is which letter.

There is nothing of O in the 79. It's a position in a table that the whole world agreed to use. That's why the same O is 79 in any machine.

see on the board → ola-mundo, cycle 8: the number 79, written 4F, which is the letter O, arrives at the machine

the math here · one-to-one correspondence between letters and numbers

number(O) = 79

read as: number of O is equal to seventy-nine.

2 · number → bits

Each number becomes eight places of yes or no

79 becomes 01001111. Eight places, each one only 0 or 1. Eight places can hold 256 different things.

before, the words of this step

house

  • What it is: a position in the writing of a number. In 79, the 7 is in one place and the 9 in another.
  • Why it exists: the place is what says how much each digit is worth: the 7 in 79 is worth seventy.

bit

  • What it is: a place that only accepts 0 or 1.
  • Why it exists: it is the smallest amount of information there is, and it is what a switch can hold: off or on.

byte

  • What it is: eight bits side by side.
  • Why it exists: it is the size of one letter, and the chunk the machine moves at a time.

It is the same idea as 79 = 70 + 9, except that each place is worth double its neighbor, not ten times. 256 is the number of combinations, not a size.

see on the board → ola-mundo, cycle 9: the eight points of the data row, lit and unlit: 0 1 0 0 1 1 1 1

the math here · positional notation in base two

79 = 64 + 8 + 4 + 2 + 1

read as: seventy-nine equals sixty-four, plus eight, plus four, plus two, plus one.

28 = 256

read as: two to the eighth equals two hundred and fifty-six: the size of the set of lists of eight zeros or ones.

where this comes from

2½ · the step that the character brought

The á does not fit in a byte

225 is greater than 127, and the original agreement only had 128 letters, without an accent. The á costs two bytes.

Eleven letters, twelve bytes. Byte is not a letter: a letter can cost one, two, three, or four. Whoever counts bytes to count letters makes a mistake, and the whole web has already made this mistake.

see it on the board → ola-mundo, cycle 19: on this machine’s screen the á fits in a single byte, E1; the two bytes belong to the file

the math here · code of variable length, without any word being the start of another

read as: bytes of o equals one; bytes of á equals two.

here it stops being written and becomes electricity

3 · bit → current

Each place becomes current in a relay

A 1 is current flowing; a 0 is current stopped. Eight relays in a row hold the O; ninety-six hold the phrase.

before, the words of this step

current

  • What it is: electricity moving through a wire, like water moving through a pipe.
  • Why it exists: it is what makes the lamp light up, the motor turn and, here, the switch flip.

relay

  • What it is: a switch that a current activates: the current of one wire closes the path of another.
  • Why it exists: it is the first piece that allows a chain to control another, without any finger.

threshold

  • What it is: the line that separates little from much. Above it the current counts as 1; below it, as 0.
  • Why it exists: the current is never exactly the same; the line is what makes two different values become the same signal.

The number is not in the relay. The relay only knows how to pass or not pass; we are the ones who agreed that passing is worth 1. Eight relays, eight places: the whole O fits in one row. How relays become gates and arithmetic is the story of the other page, the ladder.

view on the board → ola-mundo, cycle 9: each lit point in the row is a wire with current passing

the math here · threshold: an entire interval of voltages becomes a single symbol

bit(v) = 1 if v ≥ 2 volts, and 0 if v ≤ 0.8 volt

read as: bit of see is equal to one if see is greater than or equal to two volts, and equal to zero if see is less than or equal to zero point eight volt.

where this comes from

These two relays wired in series are known as an AND gate because it is performing a Boolean AND operation.Esses dois relés ligados em série são conhecidos como porta AND, porque executam a operação booleana E.eletroímã → relé (Petzold cap. 7) · relé → porta lógica (cap. 8), com o instrumento “dois relés viram uma porta”

4 · current → count and remember

The bits learn to add and to stay still.

Ports connected in one way sum two bytes. Connected in another, hold a bit after the input sums.

before, the words of this step

logic gate

  • What it is: a piece made of switches that responds yes or no to what comes to it. Two switches in a row only allow current with both closed: it's a gate.
  • Why it exists: with yes-or-no questions linked together, you build a calculation.

state

  • What it is: the way a piece is now: what it holds at this moment.
  • Why it exists: a piece that remembers its state; one that only responds no does not.

Adding 1 to O gives P, the next letter: the table was made for this to work. Now the number can be operated on and can wait. Remembering is what allows the next step.

see it on the board → ola-mundo, cycle 11: one part holds where the machine is and another adds 1: remembering and counting

the math from here · arithmetic modulo 256, and state that depends on the previous one

(79 + 1) mod 256 = 80

read as: seventy-nine plus one, modulo two hundred and fifty-six, is equal to eighty.

st+1 = f(st, xt)

read as: the state at instant tee plus one is f of: the state at instant tee, and the input at instant tee.

5 · byte → address

Each byte gets a place with a number

Memory is a row of drawers, each with a number on the door. The O is in drawer 0109; the l, in 010A.

before, the words of this step

memory

  • What it is: many drawers in a row, each with a byte inside.
  • Why it exists: to keep the entire sentence stored while the machine works on it, one letter per drawer.

address

  • What it is: the number on the door of a drawer.
  • Por que existe: to find again what was stored, without searching drawer by drawer.

Now there are two numbers per letter: what it's worth and where it is. The order of the letters has become the order of addresses. Reading the sentence is like going through neighboring drawers.

see it on the board → ola-mundo, cycle 9: the machine points to drawer 8000 and stores the 4F in it

the math of here · memory is a rule that takes each address to a byte

mem(0109) = 4F

read as: mem of zero, one, zero, nine is equal to four-efe, which is worth seventy-nine.

6 · number → order

A number is read as an order, not as a quantity.

In the same memory, next to the letters, live other bytes. CD is not a letter: it is the order “call”. C9 is “return”.

before, the words of this step

order

  • What it is: a number the machine reads as “do this”: add, copy, store, call, return. The book calls it an instruction.
  • Why it exists: without orders, the machine would only store numbers; it's the order that puts it to doing something with them.

program

  • What it is: a queue of orders, one after the other, stored in memory like any other thing.
  • Why it exists: it's like a person tells the machine what to do, all at once, so the machine can do it by itself.

program counter

  • What it is: a special drawer of the machine that stores the address of the next order.
  • Why it exists: so the machine knows which byte to read as an order now, and which comes next.

Nothing in the byte says if it is a letter or an order. What decides is where the program counter points, and that counter is also a number stored in the machine. The machine governs itself with the same material that governs.

see on the board → ola-mundo, cycle 7: the program counter points to drawer 0004 and byte 36 is read as order: store the letter

7 · words → orders

Someone writes the orders in words

No one memorizes that “call” is CD. You write CALL 5 in text, and the assembler replaces each word with the correct byte.

before, the words of this step

assembler

  • What it is: a program that reads a text with the orders written in words and replaces each word with the correct byte.
  • Why it exists: because a person remembers a word, and a machine only reads a number. Someone has to make the switch, and a program does it without error.

operating system

  • What it is: a program that already lives in the machine and provides services to other programs, like displaying text on the screen.
  • Why it exists: so each new program doesn’t need to know how the screen works.

This is where delegation begins: a person writes the intention, the machine executes. The operating system already knows how to perform services, like displaying text, so each program doesn’t need to know.

see on the board → ola-mundo, cycle 7: in the list next to it, MVI M, 'O' became 36 4F; the machine only sees the bytes

8 · execution → screen

The order turns into points of light.

The screen is also memory: each three bytes are a colored point. Showing the o is writing numbers in the correct drawers of that block.

before, the words of this step

pixel

  • What it is: a dot on the screen, too small to see on its own, with a single color.
  • Why it exists: the screen doesn’t draw letters; it lights up points, and the letter is what the points form together.

Sixty times per second the screen reads the block and lights up. Olá, Mundo! returns to being something that we read, made of numbers. How the 79 becomes the drawing of the O is the next question, still without an answer on this page.

see it on the board → ola-mundo, cycle 59: the last letter enters the screen and the whole phrase is there, made of numbers

the mathematics here · a rule that takes each point of the grid to a color

color(3, 4) = 16 23 3F

read as: color of three and four is equal to one-six, two-three, three-ef: red, green, and blue.

closing

At each step, one thing is conserved and one is forgotten

Mathematics refers to the world by what is conserved. Each layer is a promise: “You can forget the rest, this I guarantee.”

0 code

conserves the message; forgets the medium.

½ key → number

conserves the letter's code; forgets the switch, the finger.

1 letter → number

conserves which letter it is; forgets shape and sound.

2 number → bits

conserves the exact number; forgets the base ten.

2½ the á

conserves the letter and the 128 old ones; forgets “one byte, one letter”.

3 bit → current

keeps 0 and 1; forgets the physics.

4 count and memory

preserves arithmetic; forgets relays.

5 address

conserves the order of the letters; forgets the time.

6 number → order

conserves common matter; forgets “what to do” and “about what”.

7 words → orders

conserves the meaning; forgets the words.

8 order → light

keeps the recognisable shape; forgets the number.

The whole ladder is the chain of these promises, and execution is what's left when all have been fulfilled.
